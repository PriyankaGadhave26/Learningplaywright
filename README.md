# Learning Playwright

## Introduction
Welcome to the Learning Playwright repository! This project is dedicated to mastering Playwright with the help of AI. Here you will find examples, scripts, and resources to get started with end-to-end testing.

## Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/PriyankaGadhave26/Learningplaywright.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

## Usage
Run the existing scripts to see Playwright in action.
```bash
node chapter_01_Basics/01JS_basic.js
```
